# 晶体光学复习台 · 在线 H5

制作与资料汇总：**司钧霆**。学校：中国石油大学（北京）克拉玛依校区（CUPK）。学校名称用于介绍制作者背景。

用于岩石、矿物、薄片鉴定和地质学复习的浏览器学习工具。包含虚拟显微镜、矿物图鉴、岩石图鉴、薄片图库、沉积岩石、古生物地史、构造地质、普通地质、成果检测和速记表，以及构造三维观察台。

## 在线使用

本版只提供在线 H5，不提供离线安装包、整库下载或离线预缓存。图片随当前选择加载；显微镜只准备当前角度附近的少量画面。可以在显微镜和图片预览里下载当前图片。

学习记录仍保存在当前浏览器，支持原有进度备份与恢复。学习备份仅包含个人学习数据，不包含整库素材。首次从旧的本地文件页面切换到公网时，需要在旧页面导出进度，再在公网页面恢复一次：不同网址无法直接共享浏览器存储。

## 功能

- 显微镜：单偏光、正交偏光、锥光（根据原标本实际可用模式）、旋转、归零、45°定位、石膏/云母试板及实拍锥光参考。没有原始素材的模式会明确禁用。
- 图鉴与资料：分类、搜索、拼音和别名查询，图片与原始来源，教材名词、简答和复习框架。
- 构造三维台：三维块体、平面图和剖面联动观察。
- 成果检测：选择题认图、判断题、闪卡、默写、背诵、过关、智能复习、特训、薄弱项、模考和诊断。
- 学习管理：每日计划、进度、学习热力图、考试倒计时、备份恢复和 Anki 导出。
- 网站管理：右上角当前版本、新版提示和 GitHub Star；更新不会强制刷新正在使用的页面。

## 源码运行

需要 Node.js 22 或以上。无第三方 npm 运行时依赖。

```sh
npm run build
npm test
npm start
```

默认端口 9175；云端读取 `PORT`，绑定 `0.0.0.0`。不提供业务数据库或 AI 服务接口；检测、学习安排与三维计算在浏览器完成。学习数据不会发到服务器。

本代码仓库包含运行代码、整理数据及素材索引，约 1.98 GB 的媒体单独存放在[在线素材仓库](https://github.com/SJT-bright/crystal-optics-review-media)，不会随本代码仓库一起克隆。`site.json` 中的 `mediaOrigin` 指向已发布素材的固定版本标签；服务端仅转发请求路径已在清单中登记的单个文件，浏览器不会下载整库。下载单张图片时仍须保留对应来源和许可信息。

## 更新与发布

1. 修改源码或整理数据；需要升级版本号时修改 `package.json` 的 `version`。
2. 执行 `npm run build`，自动根据实际代码及数据生成构建标识，写入页面和 `public/version.json`，不用手工修改右上角。
3. 执行 `npm test`，检查当前改动涉及的桌面端与移动端交互，再将**同一构建**发布到原网站地址。

已打开的页面重新获得焦点时检查更新，保持前台时每五分钟再检查一次；发现不同构建后显示“有新版 · 更新”。用户选择刷新后才应用新版。检查失败会保留当前版本，手动检查时给出重试提示。`version.json` 和网页由服务端设置 `Cache-Control: no-store`，不使用旧离线缓存。

推送 GitHub 会执行构建和接口测试。GitHub 源码提交与公网部署是两个操作；源码推送本身不冒充线上已发布。WorkBuddy 覆盖发布会保留同一站点 URL。
