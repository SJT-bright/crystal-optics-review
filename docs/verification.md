# 在线版的验证范围

2026-10-21，程序 v1.0.3 / 构建 `d2fe3e5a21cab3fc`。制作与资料汇总：司钧霆。

## 用户使用方式

打开网站即可学习，无需准备离线资料包。浏览器按当前选择请求图片；显微镜只准备当前角度附近的少量帧，帧缓存限制为 32 MiB / 16 帧。这是显微镜模块的限制，不是浏览器总内存的测量结果。

显微镜的“下载当前画面”保存当前已绘制的 PNG；图片预览的“下载当前图片”保存当前原图。下载尚未完成或网络失败时会提示，可以再次操作。

从旧本地页面迁移时，在成果检测中导出学习记录，再到新网站恢复一次。之后保留同一网站地址，普通更新会继续使用该浏览器中的学习记录。备份文件包含学习数据，不包含图片和视频库。

## 已有交互证据

在线改造过程中实际操作了十个主要入口、练习作答与刷新持久化、图片下载失败后的重试、旧媒体缓存退役、正常及异常的版本检查。390×844 / DPR 3 与 360×780 / DPR 2 的手机浏览器模拟包含真实触摸事件、旋转和 PNG 下载，保存了截图、输入回执与真实下载文件。

版本检查还覆盖了损坏 JSON、发现新版、稍后更新不改变题目和成绩、确认刷新后读取新版并保留学习记录。更新不会自动中断正在作答的页面。

用户授权重建后，在一个新的 Ego 验收空间中继续公网实际交互：十个主要入口、六种练习模式、三关完整过关、10题模考暂停/刷新恢复/答完交卷、10张智能学习完整结束、备份实际下载、未来备份版本拒绝、有效备份恢复及取消清空。数据在更新与刷新后仍保留。

五个资料图鉴各自操作了无结果搜索、“重置全部筛选”和“清除关键词”；19种构造三维模型逐个点击切换，另操作地形随构造、构造等高线及剖面。显微镜实际切换单偏光/正交偏光/锥光与石膏、云母试板，PNG与原图均实际下载，图片预览可以切换和按Esc关闭。GitHub入口真实打开本项目仓库。

手机390×844 / DPR3和360×780 / DPR2启用移动UA与触摸能力；真实触摸旋转0→72°及下载，触摸切换偏光/试板、选择作答、设置开合与默写输入。360px默写输入宽246px，搜索框Enter不穿透答题，空答案被拦截。实拍参考视频实际播放并用键盘向后定位，关闭资料窗后视频停止。以上仍是浏览器模拟，不是物理手机验收。

本轮修复自动版本检查与手动检查重叠时缺少提示、清空搜索后旧关键词复活，以及手机图片下载按钮遮挡比例尺。最终按钮上移的公网视觉复核与发布回执在完成后记录；不把中间构建截图当作最终线上结果。

## 当前程序与公网接口

`npm test` 包含九项测试：媒体传输的鉴权、长度与哈希校验、损坏文件修复、完整性和关闭；默认禁用传输；托管符号链接启动；视频范围边界；媒体转发正常及异常；慢速响应不被响应头超时截断；普通路由、未知路径、禁止的方法与缓存头；以及自动检查尚未完成时手动点击的成功/失败两项回归。后两项在旧程序上均失败，修复后通过。

旧启动缺陷还做了负对照：旧入口在符号链接下退出且没有监听，新入口真实监听指定端口。测试记录没有将旧缺陷消失当作仅靠源码搜索得出的结论。

代码发布后由 GitHub Actions 执行构建和九项测试。历次构建与独立公网核验记录见：

- [构建与接口检查](https://github.com/SJT-bright/crystal-optics-review/actions/runs/39560997523)
- [从 GitHub 云端检查公开 HTTPS 地址](https://github.com/SJT-bright/crystal-optics-review/actions/runs/39561029318)

云端 HTTPS 检查读取了首页、匹配的版本、两张显微镜原图并核对 SHA-256，以及视频的 1024 字节 Range。另从本机检查了首末帧、视频首尾分段、非法范围 416、未知路径 404、私有配置不可访问。这些是实际网络读取，不是公网视频播放或手机操作的替代证据。

## 数据与素材边界

现有运行数据包含 60 个源标本、122 条显微序列、977 条扩展资料、1,237 个名词、1,691 个简答，学习检测池 3,979 项。程序没有添加模型 AI 服务端口；智能学习采用浏览器内的规则，因此没有虚构 AI 接口的决策与执行验收。

本地素材清单包含 10,992 个文件、1,974,525,286 字节。清单逐文件记录原始大小与 SHA-256；本次转换保留原图与原视频，不生成替代光学素材。原始资料没有提供的偏光模式与试板仍会明确提示不可用。

上述素材已完整发布到独立仓库的 `v1.0.0` 固定标签，提交 `95646d47649685e38f838838d1ba1114fbc6fd81`。发布任务逐文件核对 SHA-256，随后另取 GitHub 完整树，对全部 10,992 个远端 Git blob 与本地原件逐一比对，没有缺项或差异。源码仓库不包含这约 1.98 GB 的媒体。

还用没有任何本地媒体的源码副本实际启动服务，读取固定标签的两张显微镜原图及视频首尾两段：图片 SHA-256、视频 Range 和对应原始字节均相符，临时传输入口默认 404。新源码副本可以按需读取素材，无需先下载全库。

科学内容没有在本轮逐题重新审校 3,979 项。素材中的第三方作者、原始来源及已有许可信息继续保留；程序许可不覆盖第三方媒体。

## 以后发布

构建脚本根据程序、整理数据和素材索引生成标识，写入页面与 `version.json`。网页重新获得焦点时、保持前台每五分钟检查新版；用户确认后刷新。相同代码的重复部署不会仅因时间改变就提示功能更新。

GitHub 提交检查与公网发布是两个操作。需要先把同一构建发布到原站点地址，才能在网站右上角同步提示该构建。源码推送本身不冒充已经完成了线上部署。
